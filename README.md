## 🎮 Crónicas de Lexara — RPG para aprender inglés

En la carpeta [`juego/`](juego/) hay un RPG de mundo abierto para aprender inglés jugando.
Funciona en el navegador (ordenador y móvil), sin instalar nada: solo HTML, CSS y JavaScript.

**Historia:** Lord Hush, el Mago del Silencio, robó los Cinco Cristales de la Palabra y el reino de
Lexara olvidó cómo hablar. Con la ayuda del búho Ollie, recorres cinco mundos para recuperarlos.

| Mundo | Nivel | Temas |
|---|---|---|
| 🌳 Greenwood Meadow | A1 | saludos, colores, números, *to be* |
| 🏜️ Sunny Sands | A1+ | comida, animales, compras, *a/an*, plurales |
| 🏔️ Frost Peaks | A2 | clima, ropa, acciones, presente continuo, *can* |
| 🌙 Whispering Marsh | A2+ | preposiciones de lugar, pasado simple |
| 🏰 Sky Citadel | B1 | comparativos, futuro, condicionales + jefe final |

**Cómo se juega**

- Cada mundo es un mapa grande y libre con aldeanos, cofres con acertijos, esferas de vocabulario y enemigos.
- Ayuda a los aldeanos (preguntas, ordenar letras y frases, memoria, escucha, piedras de colores,
  recados, búsqueda del tesoro por pasos, puentes de palabras…) para ganar **runas**.
- Con 5 runas se abre el **laberinto** del mundo: solo se sale entendiendo las instrucciones en inglés
  (*Go north*, *Turn left*, *Take the red door*, *The exit is opposite the statue*…).
  Una puerta equivocada te devuelve al inicio.
- Los cuatro primeros mundos se pueden jugar en cualquier orden; el quinto se abre con 4 cristales.
- Controles: flechas / WASD, ESPACIO para interactuar, T para traducir, M para el menú. En móvil hay mando táctil.
- El progreso se guarda en el navegador (localStorage).

**Publicarlo en la web (GitHub Pages)**

1. En GitHub: *Settings → Pages*.
2. En *Source* elige *Deploy from a branch*, selecciona la rama (por ejemplo `main`) y la carpeta `/ (root)`.
3. Tras un minuto el juego estará en `https://<tu-usuario>.github.io/mi-primera-web/juego/`.
